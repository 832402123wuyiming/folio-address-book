# Folio Address Book

Folio is a browser-based address book with favorites, multiple contact methods per person, and Excel import/export. It starts empty and offers synthetic sample contacts for evaluation.

## Run

Run the following in the project directory, then open http://127.0.0.1:5173.

```sh
python -m http.server 5173 --directory dist
```

On Windows with the Python launcher, use `py -3 -m http.server 5173 --directory dist`. A static HTTP server is required for JavaScript modules. The distribution includes SheetJS, so the application can run without Internet access.

## Use the address book

- Add, edit, or delete a contact. Each contact can have any number of phone, email, social, address, or other entries.
- Use the star on a contact card to toggle its favorite status. Use **Favorites** to view only starred contacts.
- Search by name, organization, job title, notes, or contact method.
- Choose **Export Excel** to download all contacts. Exporting an empty address book produces a workbook template.
- Choose **Import Excel** to append contacts from an `.xlsx` workbook of up to 10 MB. A failed import preserves the existing address book.

Contact information is saved in browser storage for the current site and browser profile. Export a workbook before clearing browser data or moving to another device.

## Workbook format

The first worksheet contains one contact per data row. The `Name` header and a name in every populated row are required. Header matching is case-insensitive, columns may be reordered, and the other columns are optional.

| Name | Organization | Job title | Favorite | Phone | Email | Social | Address | Other | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Avery Brooks | Northstar Studio | Designer | Yes | `["00123","00124"]` | avery@example.com | @avery.design |  |  | Example contact |

For contact method columns, use a single value, separate multiple values with line breaks, or use the JSON array format generated by the exporter. Text cells preserve leading zeroes. Accepted favorite values are Yes, No, True, False, 1, and 0. A blank value defaults to No. Import appends a new contact for each row, including repeat imports.
